# Interview Generator

AI-powered platform that generates tailored interview questions based on job titles.

[Live Demo](https://deployment-url) · [API Docs](https://deployment-url.)

---

## What it does

Enter any job title and receive three thoughtful, role-specific interview questions
generated by the Gemini API. The backend validates all input, handles errors
and exposes a documented REST API.

---

## Tech stack

**Backend:** TypeScript, Express, Zod, Gemini API  
**Docs:** Swagger UI at `/docs`  
**Deploy:** Render  
**Tooling:** Biome, dotenv

---

## Quick start

```bash
git clone https://github.com/azukauteh/interview-generator.git
cd backend
yarn install
yarn dev
```

Then open `http://localhost:4000/docs` to explore the API.

See [`backend/README.md`](./backend/README.md) for full setup, environment variables, and contribution guide.
